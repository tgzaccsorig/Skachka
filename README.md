# Memes downloader (GitHub Actions)

Качает ролики по ссылкам на каналы, плейлисты или отдельные видео и отдаёт их архивом. Всё работает на серверах GitHub, ставить ничего на телефон не нужно.

## Как запустить с телефона (через сайт github.com)

1. Зайди на github.com (браузер, лучше включить «Версия для ПК») и создай аккаунт или войди.
2. Нажми **+ → New repository**, назови например `memes`, поставь **Private**, создай.
3. Нажми **Add file → Upload files** и загрузи сюда `download.py` из этого архива.
4. Нажми **Add file → Create new file**. В поле имени введи ровно:
   `.github/workflows/main.yml`
   и вставь туда содержимое файла `main.yml` из архива. Нажми **Commit changes**.
5. Открой вкладку **Actions → Download memes → Run workflow**.
6. В поле **links** вставь ссылки через пробел, например:
   `https://www.youtube.com/@КАНАЛ/shorts https://www.youtube.com/playlist?list=ID`
   В **max_videos** оставь 300. Нажми **Run workflow**.
7. Через несколько минут открой завершённый запуск, внизу в разделе **Artifacts** нажми **memes**. Скачается zip, внутри ролики.

## Важно

- YouTube Shorts качается лучше всего. TikTok часто блокирует серверы GitHub, а Инста почти всегда просит логин, там обычно не выйдет.
- YouTube иногда тоже блокирует серверы с ошибкой про «подтвердите, что вы не бот». Это нормально, попробуй другие ссылки или позже.
- Бесплатный GitHub хранит артефакты до 500 МБ суммарно, поэтому ставь 200-300 роликов за раз, а старые артефакты удаляй.
- Используй только для личного архива.
